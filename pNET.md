# proDAD pNET: The Uncomplicated Point-to-Point Networking Solution of the Amiga Era

In 1995, proDAD released *pNET*, an extremely efficient and user-friendly peer-to-peer networking solution for the Amiga platform. At a time when setting up classic computer networks was often associated with expensive additional hardware, complex driver settings, and lengthy configurations, *pNET* created a direct, uncomplicated bridge between two Amiga systems via the serial port.

---

## *pNET* (1995)

* **Software developer:** Holger Burkarth
* **Manufacturer:** proDAD GmbH
* **Platform:** Exclusive to Amiga
* **Product category:** Serial peer-to-peer network & remote management tool

### Description & Scope of Application
The main goal of *pNET* was to make data exchange and control between two Amiga computers as simple and intuitive as possible. Connected via a standard serial null-modem cable, the software turned the serial port into a full-fledged communication and data transfer interface.

### Technical Innovations & Core Functions

* **True Plug-and-Play Handling:**
  The defining feature of *pNET* was its unique ease of use. After physically connecting the serial cable, a single double-click on the program icon was enough to establish the connection immediately—without complicated network protocols or lengthy setup procedures.
* **Drive Mirroring & File Transfer:**
  *pNET* made it possible to transparently mount and mirror remote drives. Users could access the hard disks or floppy storage of the connected Amiga directly from the Workbench and exchange files seamlessly.
* **Remote Command Prompt (Remote CLI):**
  Through an integrated remote shell, the CLI (Command Line Interface) of the target Amiga could be opened and operated remotely. This allowed complete remote control of scripts, programs, and system commands.
* **Integrated Chat Function:**
  For direct communication between users at both computers, *pNET* offered a built-in chat window through which text messages could be exchanged in real time.
* **Diagnostics and Debugging Interface:**
  In addition to regular data transfer, developers and power users especially appreciated the ability to use *pNET* for debugging output. System messages, program output, and development logs could be redirected directly to the second Amiga and monitored there without burdening the running test system.

## Main Features & Unique Selling Points at a Glance

* **One-Click Connection Setup:** Connect cable, double-click, linked—no network setup.
* **Seamless Data Exchange:** Drive mirroring for easy file access via the serial port.
* **Remote Control & Remote CLI:** Full access to the remote computer's command prompt.
* **Integrated Chat System:** Direct text communication between two connected Amiga systems.
* **Versatile for Developers:** Ideal tool for outputting debugging and diagnostic data.
